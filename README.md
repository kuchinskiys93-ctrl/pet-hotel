# Хвостатый отель

Idle-игра про зоогостиницу: заселяйте шпицев и чёрных котов, кормите, выгуливайте, улучшайте номера от клетки до люкса.

## Как поставить на телефон

- **iPhone:** откройте ссылку на игру в Safari → «Поделиться» → «На экран Домой».
- **Android:** откройте в Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

После первого запуска игра работает без интернета. Прогресс хранится на самом телефоне.

## Файлы

- `index.html` — вся игра (HTML + CSS + JS).
- `manifest.webmanifest`, `icon-*.png`, `icon.svg` — иконка и настройки приложения.
- `sw.js` — офлайн-режим. При выпуске обновления поднимите версию `CACHE` в этом файле.
